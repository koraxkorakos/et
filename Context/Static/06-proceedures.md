## Content

- All source, including build scripts and design document is version controlled.
- Development does not occur in the master branch, only reintegration allowed
- Development occurs in individual features branches 
- Before reintegration coding rules must be enforced
- The master branch is always warning free and checked against static analysis and runs its unit test OK
- The unit test coverage shall be at least 80% measured on the source TBD. 
  Note: Uncovered Exception paths and unreachable code ned not be tested. Tradeoff effort versus gain-.
